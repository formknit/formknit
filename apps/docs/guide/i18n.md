# Translations

Three kinds of text appear in a form:

1. **Your own**: labels, help text and options. These are in the schema; write them in any
   language.
2. **Validation messages** such as "Full name is required".
3. **Form chrome**: the Submit, Next, Back, Add and Remove buttons.

## Nepali

```tsx
import { messagesNe } from '@formknit/core'
import { Form, labelsNe } from '@formknit/react'

<Form schema={schema} compute={{ messages: messagesNe }} labels={labelsNe} />
```

On the server, pass the same messages so errors match:

```ts
validate(schema, body, { messages: messagesNe })
```

::: tip Help improve it
The Nepali text was written without review by a professional translator. Corrections are
welcome.
:::

## Another language

Copy the shape of `defaultMessages` and `defaultLabels`. Each message is a function of the
field's label, so you control word order:

```ts
import { defaultMessages, type Messages } from '@formknit/core'

export const messagesHi: Messages = {
  ...defaultMessages,
  required: (label) => `${label} आवश्यक है`,
  min: (label, n) => `${label} कम से कम ${n} होना चाहिए`,
  // ...
}
```

Anything you leave out stays in English.
