# Security

## Reporting a problem

Please report security problems privately, not in a public issue.

Use GitHub's "Report a vulnerability" button on the repository's Security tab. Include what you
found, how to reproduce it and which package and version it affects.

You should hear back within a week. Once a fix is released, you will be credited in the release
notes unless you prefer otherwise.

## What counts

- Running code or reading data through a form schema, a formula or a submission
- Getting unsafe HTML through the rich text cleaner
- In the platform: reading or changing another workspace's data, getting past a role, taking
  over an account or session

## Supported versions

Fixes are released for the latest version only while the project is below 1.0.
